Battery Monitor (Victron)

Optional integration with a victron-bm-webui instance. It supplies real battery data (voltage, current, state of charge, estimated runtime) and a direct answer to "is mains actually gone?" — so a network outage that takes all sentinel hosts offline no longer looks like a power failure. If the service is unreachable or its readings go stale, the server silently falls back to sentinel-based detection.

When disabled, nothing changes — the server uses sentinel hosts only.
